# Materiály

Tahle složka obsahuje dvě věci: ukázkové dokumenty pro cvičení a teoretické podklady pro pochopení klíčových konceptů.

Nemusíš začínat s vlastními citlivými daty. Nejdřív si vyzkoušej principy na těchto bezpečných ukázkách a teprve potom přidej vlastní materiály.

---

## Teoretické podklady

Krátké reference — přečti si je, když tě agent na ně odkáže, nebo kdykoli budeš chtít osvěžit znalosti.

- `cursor-mody.md` — Tři módy Cursoru (Ask / Plan / Agent): co dělají, kdy je použít, typická kaskáda.
- `kontextove-okno.md` — Co je kontextové okno, kde ho vidíš v Cursoru, proč začínat každý modul novým chatem.
- `ohio-framework.md` — Only Handle It Once: tříotázkový filtr pro rozhodnutí "má tohle smysl automatizovat agentem?"
- `cursor-modely-a-kredity.md` — Co je token, co je kredit, přehled dostupných modelů a kdy přepínat.
- `human-in-the-loop.md` — Princip "AI navrhuje, člověk rozhoduje" — cvičební dokument pro Modul 3 i referenční teorie.
- `proc-markdown.md` — Proč jsou `.md` soubory pro práci s AI nejlepší volba + jak je vytvořit.

---

## Cvičební dokumenty

Používají se pro konkrétní cvičení v průběhu kurzem.

- `Můj email.md` — Sem vložíš svůj reálný e-mail. Agent z něj načte tvůj komunikační styl.
- `ukazka-dokumentu.md` — Dokument pro první otázky v Ask mode (Modul 1 a Setup).
- `ukazka-hodnoceni.md` — Vzor stylu pro pozdější práci s textem.
- `ukazka-sablony.md` — Dokument s pevnou strukturou pro práci v Plan mode.
- `sablona-zpravy.md` — Vícesekcový dokument pro cvičení diffu (Modul 3).

---

## Jak s tím pracovat

Používej `@soubor`, aby agent věděl, s čím má pracovat.

Příklad:

```text
@materialy/ukazka-dokumentu.md Co je hlavní myšlenka tohoto dokumentu?
```

## Vlastní materiály

Později sem můžeš přidat vlastní soubory: přípravy hodin, zápisy, zadání, e-maily, projektové briefy nebo jiné pracovní dokumenty.

Pokud obsahují citlivé údaje, nejdřív je anonymizuj.
