# Ukázkový nástroj

Toto je jednoduchý HTML nástroj pro Modul 5.

Zatím ho nemusíš upravovat. Slouží hlavně k tomu, aby sis později mohl/a prohlédnout, že nástroj v Cursoru nemusí být složitá aplikace. Může to být i jeden soubor, který něco malého dělá.

---

## Jak spustit

1. Otevři soubor `index.html`.
2. Otevři ho v prohlížeči.
3. Napiš jednu větu reflexe.
4. Klikni na tlačítko.

---

## Co sledovat

- Vstup: textové pole.
- Akce: kliknutí na tlačítko.
- Výstup: krátká reflexe.

Tohle je základní model nástroje: vstup → zpracování → výstup.
