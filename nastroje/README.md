# Nástroje

Tahle složka je připravená pro Modul 5.

Na začátku tu najdeš jen jednoduchý ukázkový HTML nástroj. Později sem budeš ukládat vlastní malé nástroje, které si v Cursoru vytvoříš.

---

## Co je uvnitř

- `priklad-nastroje/` — jednoduchá HTML stránka, kterou můžeš otevřít v prohlížeči.

---

## Proč tu složka je už teď

Kurz nezačíná programováním. Ale od začátku vidíš, že Cursor není jen chat na texty. Postupně se dostaneš k tomu, že popíšeš výsledek a agent ti pomůže vytvořit jednoduchý funkční nástroj.
