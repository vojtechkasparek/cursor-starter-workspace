# Agenti

Tady jsou uložené instrukce pro specializované pomocníky.

Agent není nový chat. Agent je soubor s rolí, pravidly a příklady použití. Aktivuješ ho tak, že na něj v chatu odkážeš přes `@`.

---

## První agent

Začni souborem:

```text
@agenti/agent-pomocnik.md
```

Zkus prompt:

```text
@agenti/agent-pomocnik.md Shrň mi @materialy/ukazka-dokumentu.md do 3 vět.
```

---

## Co si hlídat

- Agent pracuje lépe, když mu ukážeš konkrétní soubor.
- Pokud odpověď zní obecně, přidej kontext přes `@soubor`.
- Vlastního agenta budeš vytvářet později v kurzu.
